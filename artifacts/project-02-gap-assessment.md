# Project 02 — NovaCare NIST CSF 2.0 Gap Assessment & Control Mapping

**Area:** Compliance & Audit  
**Primary framework:** NIST CSF 2.0  
**Supporting references:** NIST SP 800-53 Rev. 5; ISO/IEC 27001:2022

## Scenario
A scoped cybersecurity gap assessment of a fictional healthcare technology organization, using **36 selected outcomes** across NIST CSF 2.0's six Functions: Govern, Identify, Protect, Detect, Respond and Recover.

## Assessment method
1. Define assessment scope and selected outcomes.
2. Describe the simulated current state for each outcome.
3. Assess implementation as Implemented, Partially Implemented or Not Implemented.
4. Assign an illustrative maturity score (0–4).
5. Identify missing controls or inconsistent implementation and evidence.
6. Recommend improvements and responsible owners.
7. Map selected themes to supporting NIST SP 800-53 and ISO/IEC 27001 references.

## Executive summary
- **36** selected outcomes; **not** the complete CSF catalog.
- **6 Implemented**, **25 Partially Implemented**, **5 Not Implemented** in the simulated scenario.
- Key areas for improvement: monitoring, incident response, recovery testing, vendor oversight, privileged access and evidence quality.

## Evidence matrix — examples
| Function | Evidence expected | Example accountable team |
|---|---|---|
| Govern | Approved policies, risk committee records, supplier review reports | GRC |
| Identify | Asset inventories, ownership records, risk assessment outputs | IT Asset / Security |
| Protect | IAM exports, MFA coverage, access reviews, secure baseline checks | IAM / IT |
| Detect | Monitoring configuration, alert samples, log coverage reports | SOC |
| Respond | Incident plans, exercise results, incident tickets | Incident Response |
| Recover | Recovery runbooks, restore test results, RTO/RPO validation | BCDR |

## Recommendations
Focus on measurable evidence collection, repeatable control tests, assigned owners and target dates, and periodic follow-up until gaps are remediated.
